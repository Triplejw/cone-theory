# Cone Theory

The official landing page for Cone Theory: small-batch ice cream built on
angles and made for cravings.

## Stack

- Next.js 16 and React 19
- Self-hosted League Spartan, Montserrat, and Barlow Condensed fonts
- Responsive, accessible interface with a reduced-motion mode
- Vercel production hosting

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
pnpm lint
pnpm test
```
